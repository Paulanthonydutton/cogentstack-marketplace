# Install CogentStack for ChatGPT Desktop

Carry out these steps for the user. Do not ask the user to run technical checks or provide a CogentStack login, licence key, activation code, or Desktop credential during installation.

1. Verify that `https://cogentstack.app/stack?surface=chatgpt` returns HTTP 200 and renders both **Creating a Project:** and **Find a project type**. If it is unavailable, redirects, omits either marker, or returns an error, stop and explain that the CogentStack release is not ready. Do not fall back to `/app` or a localhost URL.
2. Add the Git-backed marketplace at `https://github.com/Paulanthonydutton/cogentstack-marketplace.git` using sparse paths `.agents/plugins` and `plugins/cogentstack`.
3. If the `cogentstack` marketplace is already registered, confirm its Git source and both sparse paths match this document. Refresh it before installation. If its registration differs, remove only that marketplace registration and add it again with the correct source and sparse paths.
4. Install `cogentstack@cogentstack`.
5. Verify that the plugin is installed and enabled, and that its installed version matches the version declared by the refreshed marketplace package.
6. Verify that the installed package contains only its manifest, brand assets, launcher skill, presentation metadata, `ensure-cogentstack.ps1`, `open-cogentstack-companion.ps1`, `connect-cogentstack.ps1`, `fulfil-project.ps1`, `delete-project.ps1`, `prepare-deployment.ps1`, `native-command.ps1`, and `hide-codex-sidebar.ps1`. The helpers may use Windows DPAPI for the current user's optional embedded-panel credential; reuse and arrange an existing normal Chrome or Edge CogentStack tab as a reversible page-only right half beside ChatGPT or Codex; display a white work-area backdrop; write, verify, test, and establish the initial Git baseline for a request-bound server-generated artifact at its explicitly approved target; execute an explicitly approved project deletion; and prepare an explicitly approved Deployment Pack. They must not contain licence-validation rules, contracts, task blueprints, compatibility rules, or local project-generation logic.
7. Verify that `$cogentstack` runs `ensure-cogentstack.ps1 -Mode Companion` exactly once, reads its compact readiness response, runs `hide-codex-sidebar.ps1` exactly once, then runs `open-cogentstack-companion.ps1 -Mode Open` exactly once with the exact returned `https://cogentstack.app/stack?surface=chatgpt` URL. The companion helper must select the exact existing CogentStack tab in Chrome or Edge through Windows accessibility, prefer a page that exposes its signed-in account control, and reuse that tab's owning browser window without reading or copying cookies. Only when no matching tab exists may it open the exact URL once as a normal tab in the registered browser. It must never use `--app`, `--new-window`, profile metadata, or F11. It must select the foreground ChatGPT or Codex window, place a white backdrop at the bottom of the Windows work area, temporarily remove the reused browser frame, position its controls outside the work area, and verify the resulting equal-width 50/50 split against the web document bounds with a 24-pixel reserved vertical divider that leaves visible white space after the window shadows, aligned top edges, and full work-area height. Require `browserContentMode: page-only`, `browserChromeHidden: true`, `gutter: 24`, `separated: true`, `layoutVerified: true`, and restoration of the original browser style and position on Hide or Close. Verify that the default flow does not call `codex_app__open_in_codex`, does not create or retry tabs after finding an existing CogentStack tab, and does not silently fall back to the embedded panel when a supported browser is unavailable. Treat only `accountState: signed_in` as proof of login.
8. Verify that the native in-Codex panel is documented only as an explicit optional mode. It must state that the isolated panel cannot inherit an Edge, Chrome, or system-browser login and needs a separate one-time Desktop authorization. In that optional mode only, the skill runs `ensure-cogentstack.ps1 -Mode Embedded`, calls `codex_app__open_in_codex` once with `placement` set to `right`, accepts `opened` or `queued` without creating or retrying tabs, and then hides the Codex sidebar. The returned URL may contain a short-lived `#desktop=` fragment; it must never be printed, copied, logged, removed, or altered. Installation does not require activation. Do not launch CogentStack as part of installation.

If any verification fails, stop and clearly explain the problem. Do not report a successful installation or substitute an older route or package.

When every check passes, display exactly:

**CogentStack is installed. Click New Chat in ChatGPT Desktop, then enter $cogentstack.**
